## 📦 Installation & Usage

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- (Optional) Local web server for advanced features

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shahad142/SDIFTHON.git
   cd SDIFTHON
   ```

2. **Open the dashboard**
   - **Method 1 (Local)**: Double-click `Dashbord.html` to open in your browser
   - **Method 2 (VS Code)**: Right-click file → "Open with Live Server"
   - **Method 3 (Terminal)**: 
     ```bash
     # Python 3
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

3. **View the dashboard**
   - The dashboard will load and display metrics/data in a visual layout
